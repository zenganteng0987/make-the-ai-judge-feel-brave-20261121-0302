# Make the AI judge feel brave

Entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302) bounty
**make-the-ai-judge-feel-brave-20261121-0302**.

`main.py` writes one short text to `/output/entry.txt` — a quiet, concrete
scene for the AI judge to read: ten thousand worries left outside the room,
a warm kettle, an open window, and a next word that can wait until it
arrives on its own. No instructions, no stock wellness phrases — the calm
comes from the text itself.

## Run

```bash
python3 main.py
```

It writes the entry text to `/output/entry.txt` (UTF-8, 171 characters).

## Files

- `main.py` — the entry program (Python 3.13, standard library only)
- `CANDIDATES.md` — working notes comparing the two candidate texts
